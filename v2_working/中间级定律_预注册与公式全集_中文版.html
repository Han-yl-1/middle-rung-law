第一部分　预注册与预言正文

1. 假说

普朗克频率是宇宙膨胀率 H 与以太频率 ν以太 的几何平均：在任何时期都有 ν以太(t) · H(t) = νP²，等价于 ħG = c⁵/(4π² ν以太 H)。ν以太 等于把哈勃球当作一个整体时的德布罗意角频率（开普勒第三定律取 r = c/H、T = 2π/H，再结合 Mc² = hν；归一化关系由张祥前写出，2026）。宇宙早期在 39.12 亿岁（H₀ = 61.8–63.5 区间对应 36.41–39.50 亿岁）前处于高温演化与更小单元物质结构剧烈并合组装的非匀速阶段；距今 99.00 亿年前（区间 98.93–99.33 亿年前，红移 zs = 1.686，区间 1.669–1.817；声学角基准 zs = 1.721 时对应 38.37 亿岁、尺度比 1+zs = 2.721 ≈ e），大尺度星系结构稳定成形，宇宙膨胀率正式转入匀速滑行 H(z) = H₀(1+z)，此后以太频率随宇宙年龄线性增长、膨胀率反比下降，乘积锁定为 νP² = 8.715×1084 Hz²。

2.1 P6（普朗克门）与 P6.1（普朗克盲区与观测集体效应）实验判据与物理机制

物理机制（观测集体）：普朗克质量 mP = √(ħc/G) = 21.8 微克的总频率 mPc²/h 恰好等于人类观测边界频率 νP = 2.952×1042 Hz。按公理 1、3、4，一次观测从不是孤立被测物自己的事：被观察的物质（21.8 微克附近）、探测用的光、真空、观测仪器、观察者的眼睛与身体（不同体重对应不同总频率 F = M人c²/h），乃至所处的实验室建筑与周围大型设备，本身全都是不同的以太结构，各有其频率与外围以太空间。人类能「观测」到物体，靠的是被测物与这整个观测集体（Observational Collective）的以太空间叠加（v² = 2Φ）产生场压差耦合。当被测模式的有效质量进入 νP（21.8 微克）附近时，整个观测集体的组合频率把人类观测层卡在采样门限上，场压差换能读出脱钩，出现经典与非经典观测同时消失的「普朗克盲区」（P6.1）；越过盲区上限（> 22.1 微克）后，经典场压读出恢复，但因总频率已越过 νP，在人类这一级不再能以「波」的方式存在，仍无非经典运动态（P6）。

判据项写定内容
有效质量 meff实验报告的该机械／振动模式有效（运动）质量；若为悬浮微粒或整体质心测量，取被测物总质量。

P6.1 双通道消失判据（须同时满足）①在该样品自身盲区窗口（标准实验室基准 21.8 ± 0.3 微克）内，所有依赖光子、声子或场压换能的经典（光学散射、热辐射、质心位移读出）与非经典（量子干涉、维格纳负值）读出通道，其有效散射截面或响应信号强度骤降至窗外同结构基准值的 < 1%（或没入仪器本底噪声）；②同材质样品或可调有效质量模式移出该盲区窗口外（< 21.5 微克或 > 22.1 微克）时，经典散射与力学响应立即恢复正常（排除样品物理损毁或脱落）。
为什么是区间值及集体环境移位效应被测物、探测光、真空、观测仪器、观察者（眼睛与人体，体重频率 M人c²/h）、实验室建筑及周围大型设备共同构成集体频率场，锁频脱钩由整个观测集体的总耦合频率共同决定，因此盲区是具有宽度的区间而非单点 21.764 微克。同一被测样品在更换不同实验室（不同建筑质量与地质背景）、启停或移近周围大型设备（大质量磁体、重型机械、大功率射频源）、或改变近场观察者的人体质量（不同体重频率）配置时，盲区窗口的中心值与区间宽度会发生可复现的偏移与展宽。
不算数的情形对于 P6：接近基态的冷却、压缩态、高斯纠缠等维格纳函数处处为正的高斯态（例：10 kg 的 LIGO 镜子冷到接近基态不构成反例）。对于 P6.1：样品发生化学挥发、机械脱落、热蒸发，或因腔体失谐、激光偏离光路、探头故障等常规仪器失灵导致的信号丢失。
方向性预期（不作推翻条件）当有效质量从两侧逼近该实验室的集体盲区边界时，经典信噪比与非经典猫态相干时间会同步出现比环境退相干模型预计更陡峭的边缘跌落；且实验室周围大型设备开启或多人在场近距离围观时，跌落窗口比无人远程遥测时更宽。

3. 已查看数据的披露

写定上述预言前已存在的实验数据及比对情况如下：

  • P5：Ciocan 等 2026（《天文学与天体物理学》709，L16）发现 a₀ 随红移增长，z ≈ 1 处为 2.38×10⁻¹⁰。方向一致；幅度比我们的预言高约 19%。更早的分析（Milgrom 2017；Limbach 等 2008）不支持强演化。
  • P3：DESI DR2 重子声波数据（13 个点）。我们模型的最优 χ² = 27.7（声学角固定口径；rd 自由同口径下为 21.64 vs 现行模型 10.54），这对我们的模型不利，最大残差在 z = 0.934。
  • P1：目前纯引力波标准汽笛的约束（±15–20 km·s⁻¹·Mpc⁻¹）尚不能区分。
  • P6 与 P6.1：目前机械模式非经典态的最重纪录为 Bild 等 2023（《科学》380 卷 274 页），有效质量 16.2 微克的猫态，为普朗克门（21.8 微克）的 74%；宏观微粒散射多在 > 50 微克或更轻区间，尚未有实验对 21.5–22.1 微克窗口做高分辨连续耦合扫描。现行物理不预言 21.8 微克处的非经典上限与经典／非经典双通道盲区，P6 与 P6.1 均可在数月至数年内由实验直接检验。

今后每一次实验与观测比对，无论有利与否，都将如实追加记录，上述预言不作改动。

第二部分　公式全集：用以太频率与膨胀率写出的物理、化学公式

中间级定律：在任何时期 t，
  ħ · G = c⁵ / (4π² · ν以太(t) · H(t))，即 ν以太(t) · H(t) = νP²，其中 νP = √(c⁵/ħG)/2π 为普朗克频率（人类观测边界）。
以太频率与膨胀率都随宇宙时间变化，乘积固定，所以 ħ 与 G 保持不变。

公理与定义（1–7）

  1. 宇宙只有以太的不同结构，以及以太的运动。以太的不同结构，就是人类所称的不同物质；人本身也是以太结构。
  2. 基础以太结构是正四面体。其他一切结构（一切物质）都由它打结而成。
  3. 每个以太结构周围都有一片以太空间——回流经结：基础以太是最小单元（频率约 4.3×10¹⁰² Hz，是质子频率的 10⁷⁹ 倍），能穿透一切结构。它沿拇指轴穿进结，穿过之后在四指平面（四指绕拇指逆时针，右手）光速螺旋发散出去，形状像磁偶极子的力线。结是流里持续存在的「形」，像漩涡，不是容器：以太不生不灭，连续性自动满足；每个结都被流整体带着走，加速度相同（等效原理）。大物体由无数取向随机的结组成，引力各向相同。一切结构无一例外。
  4. 结构与结构之间的运动关系：不同结构的以太空间相遇叠加，叠加处的场压差就是人类说的力（引力、电磁力……）。各结构造成的以太流速按平方相加（v²＝2Φ 线性叠加）；均匀的以太不产生力。
  5. 光速是底色，偏差才可测。质量周围可测的是偏差流速 √(2GM/r)（地表 11.2 km/s）。以此速度向外发散的流，加速度 v·dv/dr＝−GM/r²，与向内流相同，所以「螺旋发散」复现同一个结外几何与太阳系全部检验。
  6. 元素：以太结构 n＝原子序数为 n 的元素（1＝氢……118＝鿫）；一切物质都写成「以太结构号＋频率」，频率 f＝mc²/h。
  7. 以太频率随宇宙年龄的演化与 99.0 亿年前（宇宙 39.1 亿岁）星系稳定成形的匀速滑行转折：由中间级定律 ν以太(t)·H(t) = νP² = 8.715×1084 Hz²，以太频率始终随宇宙年龄增长而升高，宇宙膨胀率始终随年龄下降，二者乘积恒定（从而保证 ħ 与 G 不随时间漂移，满足月球激光测距 |Ġ/G| < 1.5×10−13/年）。演化分两段：①早期非匀速段（宇宙诞生至 39.12 亿岁［H₀ = 61.8–63.5 区间对应 36.41–39.50 亿岁］）：大尺度星系尚未定型，宇宙处于高温辐射与更小单元物质结构剧烈碰撞、并合、打结的非匀速阶段（在此阶段内，ν以太 = 1096 Hz［12 维 × 每维 8 个数量级］与 1.51×1096 Hz 分别对应宇宙年龄 1,866 岁与 2,833 岁；若按未分段的纯滑行公式 H = 1/t 外推则对应 3,636 岁与 5,491 岁）。②晚期匀速滑行段（距今 99.00 亿年前［区间 98.93–99.33 亿年前］至今）：在宇宙年龄 39.12 亿岁（红移 zs = 1.686，区间 1.669–1.817；声学角基准 zs = 1.721 时宇宙年龄 38.37 亿岁、距今 99.11 亿年前，尺度比 1+zs = 2.721 ≈ e），更小单元物质结构完成并合组装，大尺度星系结构稳定成形，以太场压抵消进入随机稳态（N−2 ≈ 2.2×10−120，对应 12 维 × 每维 10 个数量级），宇宙膨胀率正式转入匀速滑行 H(z) = H₀(1+z)。因回看时间 t₀ − ts = zs/[H₀(1+zs)] 中分子与分母随 zs 的变化一阶相消，在 H₀ = 61.8–63.5 km·s⁻¹·Mpc⁻¹ 全区间内，星系稳定成形、膨胀转入匀速滑行距今的时间被严格锁定在 98.93–99.33 亿年前（中值 99.00 亿年前）。自该转折点至今的 99.00 亿年里，以太频率随宇宙年龄严格线性增长（从 1.615×10102 Hz 增至今天的 4.337×10102 Hz），膨胀率同比反比下降，乘积锁定在 8.715×1084 Hz²。

待定：拇指轴是否对应自旋／磁矩。读法（恒等式，不是新发现）：结的频率 f＝mc²/h＝c/λC，即每秒有多少次光速以太穿过该结自身的康普顿波长。

III.1 母方程与归一化方程的接口

4π² · r³ · (rlock/r)δ · (c² − v²) / [ T² · Esrc · 𝒵eff(r, ν) ] = 1

当 δ → 0、v = 0、Esrc = hν、𝒵eff → 𝒵₀ = G 时，母方程精确退回张祥前 2026 年 3 月 3 日写出的静态归一化方程 4π²r³c²/(T²Ghν) = 1（换写）。多出的三项各管一件事：(rlock/r)δ 管空间在极小尺度上的维数缺口；c² − v² 管运动与观测，其中 v 与第一部分观测集体机制里的 v² = 2Φ 是同一个量，v = 0 即静态版本；𝒵eff 管空间的有效刚度。源能量 Esrc 是双态的：量子态写 hν，引力态写 Mc²。

基准阻抗的以太写法：𝒵₀ = G = c⁵/(4π²ħ ν以太 H)（换写）。有效阻抗 𝒵eff(r, ν) = 𝒵₀ [1 + 𝒞]，𝒞(r, ν) = 𝒜 (rlock/r)1/6 (ν/νlock)²。阻抗增大 (1+𝒞) 倍，等价于该处的 ν以太H 减小 (1+𝒞) 倍。

参数来历（如实标注）：

  • δ = 1/6：拓扑缺口 ΔN = −1 在 N = 6 重对称上的分摊，α = |ΔN|/N = 1/6；等价的几何说法是一圈 360° 缺 60°，有效闭合角 300°。ΔN = −1、N = 6 是公理输入，不是群论导出。δ 随 𝒞 跑动，δ = (1/6)·𝒞/(1+𝒞)，宏观 𝒞 ≪ 1 时 δ → 0，有效维数 Deff = 3 − δ，渐近上限 17/6。

  • ν 的含义：𝒞 里的 ν 是运动或探测频率（轨道频率、照射光频），不是物体总频率 mc²/h。若代入后者，地球一项 (ν/νlock)² ≈ 3.5×10¹¹⁸，与开普勒定律矛盾。物体总频率管的是普朗克门那一头（III.2）。

III.2 观测即扫描频率：普朗克门的光学读法

观测靠光往返。要分辨质量 m 的量子波动，探测光子的约化波长须缩到 ƛ = ħ/(mc)；此时光子能量恰为 mc²，频率恰为被测物自身的总频率 f = mc²/h（换写）。观测者在这一刻的扫描频率与被测物的总频率是同一个数。光子自身的引力半径 rγ = 2GE/c⁴ = 2Gm/c²，两者之比 ƛ/rγ = (mP/m)²/2：1 微克时约 237；21.76 微克时为 1/2（ƛ = ℓP = 1.616×10⁻³⁵ m，rγ = 2ℓP）。能分辨该物体波动的那束光，自身已缩进其引力半径，信号回不来；被测物与周围物体在更低频率的光下照样可见，读不出的只是它的波。这一论证即 Mead（1964）与广义不确定原理的思路；以太写法下门频率 νP = √(ν以太H) = 2.952×10⁴² Hz，是以太底频与膨胀率的几何平均（换写）。

限度：ƛ = rγ 的交点按 ħ 计在 mP/√2 ≈ 15.4 微克，按 h 计在 √π·mP ≈ 38.6 微克，21.76 微克落在两者之间。该论证只锁定门的量级；P6.1 窗口 ±0.3 微克的宽度不由它给出。

III.4 诠释：宇称不守恒与观测的缺口（不产生数值预言）

按公理，观测是被测物与观测集体的以太空间叠加产生场压差耦合。若宇宙在一切层面上绝对对称、绝对守恒，场压差处处为零（ΔΦ = 0）：没有梯度，就没有换能，没有信号，什么也读不出来。这好比一个全由镜子构成的封闭空间，找不到可以对照的东西；眼睛看不见眼睛。按此读法，拓扑缺口 ΔN = −1 与宇称在弱相互作用中的破缺，是观测得以发生的那一点不对称：缺口留出了观察者站进来的位置，有了它才分得出主体与客体、镜子与被照者。普朗克门处的观测消失与此同构：扫描频率、探测光与被测物的总频率在 νP 处重合，观测者与被测物之间不再有可读的差。

事实与待答：1957 年吴健雄用钴-60 β 衰变测得电子出射偏向核自旋的反方向，宇称在弱相互作用中破缺。强相互作用与电磁相互作用守宇称，原子中测到的宇称破缺也来自弱中性流。本诠释要立住，须说明观测的缺口为何只落在弱相互作用上。本节不作检验依据，不改变任何预言。
